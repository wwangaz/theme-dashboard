GitHub 同步设置

日志保存到 GitHub 仓库，需要一个有 Contents: Read & Write 权限的 Personal Access Token。

  1. 前往 GitHub → Settings → Developer settings → Fine-grained tokens
  2. 选择仓库 wwangaz/theme-dashboard
  3. Permissions → Repository permissions → Contents → Read and write
  4. 生成后粘贴到下方
